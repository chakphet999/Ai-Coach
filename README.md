# AI Coach

เว็บช่วยวางแผนฝึกกีฬาและบันทึกผลการซ้อม โดยใช้ AI ช่วยแนะนำแผนตามกีฬาและเป้าหมายที่เลือก

## ฟีเจอร์

- สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมล/รหัสผ่าน
- รองรับ 14 กีฬา: วิ่ง ฟุตบอล บาสเกตบอล แบดมินตัน ฟันดาบ ว่ายน้ำ ปั่นจักรยาน วอลเลย์บอล เทนนิส HYROX เวทเทรนนิง มวย ปิงปอง และศิลปะการต่อสู้
- เลือกสิ่งที่ต้องการฝึก เช่น ความอึด ความเร็ว ความแข็งแรง เทคนิค ความคล่องตัว หรือเตรียมแข่งขัน
- ให้ Gemini สร้างแผนรายสัปดาห์จากกีฬา เป้าหมาย ระดับประสบการณ์ เวลาที่มี อุปกรณ์ ความล้า และประวัติฝึก 14 รายการล่าสุด
- บันทึกการฝึกและแผน AI แยกตามบัญชี
- ดูประวัติแผนและประวัติการฝึกย้อนหลัง
- ไม่ต้องติดตั้ง npm packages เพิ่มเติม
