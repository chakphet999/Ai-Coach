# AI Coach

เว็บผู้ช่วยฝึกกีฬาที่ให้ผู้ใช้สมัครสมาชิก เลือกกีฬาและเป้าหมาย แล้วขอให้ Gemini ช่วยสร้างหรือปรับแผนจากข้อมูลที่กรอกและประวัติการฝึก

## ฟีเจอร์

- สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมล/รหัสผ่าน
- รองรับ 14 กีฬา: วิ่ง ฟุตบอล บาสเกตบอล แบดมินตัน ฟันดาบ ว่ายน้ำ ปั่นจักรยาน วอลเลย์บอล เทนนิส HYROX เวทเทรนนิง มวย ปิงปอง และศิลปะการต่อสู้
- เลือกสิ่งที่ต้องการฝึก เช่น ความอึด ความเร็ว ความแข็งแรง เทคนิค ความคล่องตัว หรือเตรียมแข่งขัน
- ให้ Gemini สร้างแผนรายสัปดาห์จากกีฬา เป้าหมาย ระดับประสบการณ์ เวลาที่มี อุปกรณ์ ความล้า และประวัติฝึก 14 รายการล่าสุด
- บันทึกการฝึกและแผน AI แยกตามบัญชี
- ดูประวัติแผนและประวัติการฝึกย้อนหลัง
- ไม่ต้องติดตั้ง npm packages เพิ่มเติม

## สิ่งที่ต้องมี

- Node.js 18 ขึ้นไป
- Gemini API key จาก [Google AI Studio](https://aistudio.google.com/app/apikey)

คีย์ที่เคยส่งในแชตให้ถือว่าเปิดเผยแล้ว ให้เพิกถอนคีย์เดิมและสร้างคีย์ใหม่ ห้ามใส่คีย์ลงหน้าเว็บหรือส่งให้ผู้อื่น

## ตั้งค่า API key บน Windows

1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ `hyrox-ai-coach` ใน VS Code
2. คัดลอกไฟล์ `.env.example` แล้ววางไว้ในโฟลเดอร์เดิม
3. เปลี่ยนชื่อสำเนาเป็น `.env` โดยลบ `.example` ออก (ตรวจว่าไม่ได้กลายเป็น `.env.txt`)
4. เปิด `.env` แล้วแทน `ใส่คีย์ของคุณตรงนี้` ด้วย API key ใหม่ที่สร้างเอง บันทึกไฟล์

ตัวอย่างรูปแบบ:

```env
GEMINI_API_KEY=วางคีย์ใหม่ของคุณตรงนี้
GEMINI_MODEL=gemini-3.8-flash
PORT=3000
```

## เปิดเว็บ

เปิด Terminal ใน VS Code ที่โฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
node server.js
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` จากนั้นเลือก **สร้างบัญชี** เพื่อเริ่มใช้

## ข้อมูลบัญชีและประวัติ

- บัญชี ประวัติแผน และประวัติการฝึกเก็บใน `data/app-data.json` บนเครื่องที่รันเซิร์ฟเวอร์
- รหัสผ่านถูกเก็บเป็นค่าแฮช ไม่ได้บันทึกเป็นข้อความธรรมดา
- เซสชันเข้าสู่ระบบอยู่ในหน่วยความจำของเซิร์ฟเวอร์ เมื่อปิดหรือเริ่มเซิร์ฟเวอร์ใหม่ ผู้ใช้ต้องเข้าสู่ระบบอีกครั้ง
- ห้ามแชร์ `data/app-data.json` เพราะมีข้อมูลบัญชีและประวัติของผู้ใช้

## ความเป็นส่วนตัวและข้อจำกัด

- เมื่อสร้างแผน ระบบส่งข้อมูลกีฬา เป้าหมาย ความพร้อม และประวัติการฝึกไปให้ Gemini ประมวลผล โดยตั้ง `store: false` ในคำขอ
- นี่เป็นโปรเจกต์เพื่อการเรียนรู้ ไม่ใช่ระบบยืนยันตัวตนสำหรับเปิดสาธารณะ ก่อนนำไปเผยแพร่จริงควรเพิ่ม HTTPS, การจำกัดความถี่ในการล็อกอิน, การจัดการเซสชันแบบถาวร และฐานข้อมูลที่เหมาะกับผู้ใช้หลายคน
- AI ให้ข้อมูลทั่วไป ไม่ใช่การวินิจฉัยหรือการรักษา หากมีอาการเจ็บหรือปวดมาก ให้หยุดฝึกและปรึกษาผู้เชี่ยวชาญ
- โควตาและค่าใช้บริการ Gemini ขึ้นอยู่กับบัญชีและเงื่อนไขของ Google AI Studio
