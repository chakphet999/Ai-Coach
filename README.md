# AI Coach

เว็บช่วยวางแผนฝึกกีฬาและบันทึกผลการซ้อม โดยใช้ Gemini ช่วยแนะนำแผนตามกีฬาและเป้าหมายที่เลือก

## ฟีเจอร์

- สมัครสมาชิกและเข้าสู่ระบบ
- เลือกกีฬาและสิ่งที่ต้องการฝึก
- สร้างหรือปรับแผนด้วย Gemini
- ลองส่งคำขอใหม่เมื่อ Gemini ตอบ 429/503 และสลับไปโมเดลสำรองเมื่อโมเดลหลักยังใช้งานไม่ได้
- บันทึกและดูประวัติการฝึก
- ขอรีเซ็ตรหัสผ่านทางอีเมลด้วยลิงก์ใช้ครั้งเดียว อายุ 15 นาที

## รันในเครื่อง

ต้องติดตั้ง Node.js และตั้งค่า Gemini API key ในไฟล์ `.env` ก่อน จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:

```bash
npm start
```

เปิด `http://localhost:3000`

## Deploy บน Render

1. Push โปรเจกต์ขึ้น GitHub
2. ใน Render เลือก **New → Blueprint** แล้วเชื่อม Repository นี้
3. ใส่ Gemini API key เมื่อ Render ขอ จากนั้นเริ่ม Deploy

ไฟล์ `render.yaml` ตั้งค่าคำสั่ง Build และ Start ไว้แล้ว อย่าใส่ API key ลงใน GitHub หรือ `render.yaml`

ระบบใช้ `gemini-3.8-flash` เป็นโมเดลหลัก และ `gemini-3.6-flash` เป็นโมเดลสำรอง ค่าเริ่มต้นตั้งไว้ในโค้ดและ `render.yaml` แล้ว ปรับได้ด้วย `GEMINI_MODEL` และ `GEMINI_FALLBACK_MODEL` ใน Render Environment

### ตั้งค่าการรีเซ็ตรหัสผ่าน

ฟีเจอร์นี้ส่งอีเมลผ่าน Resend และต้องตั้งค่า Environment Variables ใน Render:

| Key | Value |
| --- | --- |
| `RESEND_API_KEY` | API key จาก Resend |
| `RESET_EMAIL_FROM` | อีเมลผู้ส่งจากโดเมนที่ยืนยันแล้วใน Resend เช่น `AI Coach <support@example.com>` |
| `APP_BASE_URL` | URL ของเว็บ เช่น `https://ai-coach-fwra.onrender.com` |

อย่าใส่คีย์เหล่านี้ใน GitHub หรือส่งผ่านแชต ลิงก์รีเซ็ตใช้ได้ครั้งเดียวและหมดอายุใน 15 นาที

> Render แผนฟรีเหมาะกับการสาธิต เว็บอาจพักเมื่อไม่มีคนใช้ และไฟล์ข้อมูลในเครื่องอาจหายเมื่อบริการรีสตาร์ตหรือ Deploy ใหม่ จึงไม่ควรใช้กับบัญชีหรือประวัติจริงที่ต้องเก็บถาวร

## ข้อมูลส่วนตัว

ไฟล์ `.env` มี API key และ `data/app-data.json` มีข้อมูลบัญชีกับประวัติผู้ใช้ อย่าอัปโหลดหรือแชร์ไฟล์เหล่านี้

สำหรับรันในเครื่อง สามารถเพิ่ม `RESEND_API_KEY`, `RESET_EMAIL_FROM` และ `APP_BASE_URL=http://localhost:3000` ลงใน `.env` ได้ โดยต้องมีอีเมลผู้ส่งที่ Resend อนุญาตให้ส่งด้วย

AI Coach ให้ข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ หากมีอาการเจ็บหรือปวดมาก ให้หยุดฝึกและปรึกษาผู้เชี่ยวชาญ
